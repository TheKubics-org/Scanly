08 / PRIVACY

Your documents
stay yours.

Scanly is designed around user-controlled document storage and explicit permissions. We believe document scanners shouldn't hold your data hostage.

✓

Local-First Workflow

Scans and generated PDFs are created and stored strictly in the private application sandbox on your device.

✓

Permission-Based Access

Camera and file storage access are requested only when executing scanning or exporting operations.

✓

Controlled Sharing

Documents are never uploaded to any remote server unless you explicitly authenticate and trigger cloud backup.

✓

Biometric App Lock

Integrate device fingerprint or face unlock to guard sensitive scans against unauthorized local physical access.

✓

User-Controlled Deletion

Deleting a document or clearing cache instantly wipes the underlying files from device storage without recovery remnants.
